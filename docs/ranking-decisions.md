# Рішення A0/A6 щодо консервативного ранжування MVP

Статус: робоче інтеграційне рішення; воно змінює суперечливі частини початкового
дизайну. Регіональні числові параметри залишаються чернетками. DEMO активується
лише коли одночасно `rules.demo=true` та `snapshot.demo=true`.

## Суперечності початкових вимог

**Економічні слоти не гарантують «пропуск не покращує».** Нехай агрономічні
місця A=1, B=2. Обидві культури мають повну економіку, але маржа B вища.
Правило §5.7 дає B=1, A=2. Якщо видалити економіку A, повних комплектів
залишається менше двох, перестановка зникає: A=1, B=2. Отже видалення даних
покращило A. Це контрприклад твердженню §5.7 незалежно від конкретних чисел.

**Розширення інтервалу може поліпшити економічне місце.** Культура з нижчого
ярусу та високою маржею може потрапити до вищого ярусу після розширення її
`hi` через пропуск. Потім економічна перестановка підніме її над раніше
вищими культурами. Саме використання нижньої межі для початкового сортування
ще не виправляє такої перестановки.

**Збір непослідовних перекриттів також змінює порядок.** A=[.8,.85,.9],
B=[.6,.65,.7], C=[.5,.7,.95]. Збір усіх інтервалів, що перекривають A,
створює перший ярус A,C, залишаючи B нижче. Широкий інтервал C покращив її
позицію перед B, хоча нижня межа C гірша.

**Жорсткі бар'єри мають іншу семантику пропусків.** Надійний факт несумісності
виключає культуру. Видалення цього факту переводить її в умовну, бо без
доказів жорстке виключення заборонене. Абсолютна гарантія кінцевого місця,
яка включає виключених кандидатів, суперечила б G3.

## Поведінка MVP

1. Основний агрономічний ключ — `Agro.lo` за спаданням. Після нього всередині
   точних рівностей нижньої межі порівнюється сценарна маржа, далі `Agro.mid`,
   далі сталий ідентифікатор культури. Рівність тут точна; epsilon використовується
   лише для інформаційної позначки близьких оцінок.
2. Ярус є послідовним префіксом поточного списку за нижньою межею. Він
   закінчується на першому інтервалі, що не перекриває нижню межу лідера.
   Після цього починається наступний ярус. Економіка не переносить культури
   між ярусами та не переставляє різні нижні межі.
3. Відсутня повна економіка має найгірший економічний ключ серед точних
   агрономічних рівностей. Правило збереження початкових слотів не застосовується.
   Видалення економіки кандидата може погіршити його місце, але не покращити.
4. Невідома сівозміна розширює інтервал до затверджених/DEMO меж; невідома
   погода використовує відповідний затверджений/DEMO інтервал. Відомі штрафи
   не зникають під час агрегації. Супутник не входить у бал чи бар'єри.
5. Перевірка стійкості реально перераховує інтервали, яруси, економічний
   ключ та фінальний відбір на детермінованому декартовому добутку. Виміри:
   сила сівозміни, увімкнення погоди, правило ярусів; за наявності даних —
   майбутній клімат, ціна, витрати та альтернативний рівень агротехнологій.
   Якщо сітка перевищує 300 сценаріїв, витрати представлені двома крайніми
   значеннями. Базовий результат обчислюється окремо. Максимум — 288 сценаріїв.
6. Для припущеного рівня агротехнологій відсутні альтернативні шари означають
   `stability.label=unavailable` і запит уточнення, а не оцінену стійкість
   до цього чинника. Якщо склад топ-5 змінюється між доступними рівнями,
   результат має режим `NEEDS_INPUT`.

## Межі гарантій і відмінності від дизайну

Гарантія стосується нижньої числової оцінки та пріоритету вже оціненого
кандидата при видаленні його даних сівозміни, погоди чи економіки, коли
калібровані інтервали невідомого охоплюють можливі відомі значення. Вона
не поширюється на зміну допуску G1–G5, іншого кандидата, цілого набору
доказів або агрономічних правил. Зміна правил/параметрів створює іншу версію.

Видалення необов'язкового дрібного/майбутнього шару GAEZ зараз може звузити
інтервал: мінімум і максимум утворюються лише з доступних шарів. Для строгої
гарантії на таке видалення потрібен контракт очікуваних шарів і консервативні
межі відсутнього шару. Їх поки немає. Покриття .5–.8 без буферних комірок
має нижню межу 0, а не вигаданий мінімум відсутніх сусідів. Fallback SXX має
передбачений дизайном інженерний множник .8 з явною позначкою.

Числова агрономія прикладу §8 перевіряється golden-тестом. Його початковий
фінальний порядок за економічними слотами навмисно не використовується як
еталон після цього рішення. Зокрема, без економіки `pea_dry` з `lo=.62`
розміщується вище `sugar_beet` з `lo=.60`. MVP не заявляє повної відповідності
початковим взаємно суперечливим правилам §5.6–§5.8.

Додаткові консервативні обмеження: G4 потребує класу 8 на обох роздільностях
в обох періодах і не застосовується проти надійної історії успішного вирощування;
лише озимі без підтвердження звільнення поля стають умовними. Умовні кандидати
не заповнюють список самостійно, їх максимум два, і їхній ярус не гірший за
останній доступний безумовний у межах ліміту. Ці обмеження пояснюються у trace.
